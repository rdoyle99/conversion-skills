# Common dead-click patterns

- Feature cards styled like links with no href.
- Logos in a "used by" strip that people expect to open a case study.
- Screenshots people tap to enlarge.
- A button under a transparent overlay (cookie banner container, chat widget frame).
- Pricing plan names that look like tabs.

For each: either make it do the expected thing, or remove the hover and pointer styling so it stops inviting a tap.
