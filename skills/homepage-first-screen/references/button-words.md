# Words that count as a main button

The YC check (2026-10-28) counted a button as the main one when its text contained a sign-up, demo or get-started
phrase: "get started", "book a demo", "sign up", "join the waitlist" and about 40 more. The most common on those
378 homepages: "book a demo" (78), "contact" (25), "get started" (20), "sign up" (15), "book a call" (14).

A site whose main action uses other words ("copy prompt", "install") was counted as having no main button. If your
main action is an install command or a copy button, say so in `.agents/conversion.md` and check it the same way.
