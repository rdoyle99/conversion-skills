# Questions to answer from the repo before asking the user

1. Where is the homepage rendered? (search for the root route, `index.html`, `app/page.tsx`, `pages/index`)
2. What does the main call-to-action say, and what does its handler or href do?
3. Is there a sign-up, checkout or booking route? What URL does a finished one land on?
4. Which analytics script loads (look for gtag, plausible, posthog, datafast, umami, a UserProof snippet)?
5. Is there a pricing page, and do its prices come from code or from copy?

Ask the user only what the repo can't answer, in one message.
