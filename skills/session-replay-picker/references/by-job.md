# Pick by job

| Job | Fits | Wrong for |
|---|---|---|
| Free recordings and heatmaps, watched by hand | Microsoft Clarity | teams that want the tool to rank what to fix |
| Product analytics with replay in one place | PostHog | sites that only want replay, at high volume |
| Frontend debugging with network and console | LogRocket, Sentry | a founder who wants one conversion fix |
| Marketing heatmaps and surveys | Hotjar | a coding-agent workflow |
| A coding agent handed one fix with file and line | UserProof (publishes this repo) | heatmaps, surveys, analyst dashboards |
